# 연말 행사 실시간 참여 웹앱

워드클라우드 · 투표 · 퀴즈(4지선다/OX) · 빙고 · 경품 추첨 · 개인/팀 순위를 한 URL로 진행합니다.

| 화면 | 주소 | 누가 |
|---|---|---|
| 참가자 | `.../yearend/index.html` | 구성원 (사전 배포) |
| 진행자 | `.../yearend/host.html?key=hynix2026` | 진행자 노트북 |
| 대형 화면 | `.../yearend/screen.html` | 프로젝터 |

진행자가 화면에서 순서를 클릭하면 참가자 폰과 대형 화면이 함께 바뀝니다.

---

## 1. 먼저 브라우저로 미리 보기 (Firebase 없이)
주소 끝에 `?demo=1`을 붙이면 같은 브라우저의 탭끼리만 연결되는 데모 모드로 열립니다.
`host.html?demo=1&key=hynix2026`, `screen.html?demo=1`, `index.html?demo=1`을 탭 여러 개로 열어 보세요. 참가자 탭을 여러 개 열면 각각 다른 사람이 됩니다.

## 2. Firebase 준비 (상반기 프로젝트 재사용)
1. **요금제를 Blaze로 바꿉니다.** 무료(Spark) 요금제는 동시 접속이 100명으로 제한됩니다. 하루 행사 규모라면 실제 청구액은 보통 0원에 가깝습니다.
2. 콘솔 → Realtime Database → **규칙** 탭에 아래 내용을 붙여넣고 **게시**합니다. 상반기의 테스트 모드는 30일 뒤 자동으로 잠기기 때문에 이 단계가 꼭 필요합니다.
   ```json
   {
     "rules": {
       "yearend":      { ".read": true, ".write": true },
       "rooms":        { ".read": true, ".write": true },
       "oxquiz_rooms": { ".read": true, ".write": true }
     }
   }
   ```
   `rooms`와 `oxquiz_rooms`는 상반기 빙고와 OX 퀴즈가 쓰던 경로입니다. 더 이상 쓰지 않으면 지워도 됩니다.
3. `config.js`의 `databaseURL`이 콘솔의 Realtime Database 화면 상단 주소와 같은지 확인합니다.

## 3. GitHub Pages에 올리기
기존 저장소 `niceman88/company-bingo`에서 **Add file → Upload files**를 누르고, `yearend` **폴더째** 끌어다 놓은 뒤 Commit합니다.
1~2분 뒤 아래 주소로 접속됩니다.
- 참가자: `https://niceman88.github.io/company-bingo/yearend/`
- 진행자: `https://niceman88.github.io/company-bingo/yearend/host.html?key=hynix2026`
- 대형 화면: `https://niceman88.github.io/company-bingo/yearend/screen.html`

수정한 파일을 다시 올렸는데 화면이 그대로라면 Ctrl+Shift+R(강력 새로고침)을 누르거나 시크릿 창에서 열어 보세요.

## 4. 설정 (`config.js`)
- `EVENT_ID`: 데이터를 저장하는 칸 이름입니다. 리허설은 주소 끝에 `?event=rehearsal`을 붙여서 하면 본행사 데이터와 섞이지 않습니다. 이때 진행자·대형 화면·참가자 주소에 모두 같은 값을 붙여야 합니다.
- `HOST_KEY`: 진행자 화면 비밀번호입니다. 꼭 바꾸세요. (파일 안에 그대로 보이는 값이라 강한 보안은 아니고, 참가자가 실수로 진행자 화면에 들어오는 것을 막는 정도입니다.)

## 5. 콘텐츠 작성법
### 📌 세션
```
[세션] 2. 개인전 퀴즈
부제: '26년 퀴즈왕은?
소개 문장 (여러 줄 가능)
```
- 세션 순서를 열면 대형 화면과 폰에 **세션 소개 페이지**가 나옵니다. 이번 세션 순서, 진행 방식, 상품은 자동으로 채워집니다.
- **순위는 같은 세션 안의 점수만** 집계합니다. 예를 들어 퀴즈 세션의 `[순위 퀴즈]`는 그 세션의 퀴즈 점수만 셉니다.
- **개인 퀴즈 동점:** 점수 → 맞힌 문제 수 → 정답까지 걸린 시간 합계(짧을수록 위) 순으로 가립니다.
- **팀전 동점:** 팀전 점수 → 팀 게임 1등 횟수 → 2등 횟수 → … → 마지막 팀 게임 순위 순으로 가립니다.

진행자 화면 → **콘텐츠** 탭 왼쪽에 전체 작성법이 있습니다. 고친 뒤 **저장**하면 모든 화면에 바로 반영됩니다.

- **개인 순서:** `[워드클라우드]` `[투표]` `[퀴즈 20초]` `[OX 10초]` `[빙고 5x5 3줄]` `[추첨 3명]` `[순위 퀴즈]`
- **팀 게임:** `[탭레이스 10초]` `[팀퀴즈 20초]` `[반응속도 3회]` `[초성퀴즈 60초]` `[타이밍 10초]` `[팀순위]` (예비: `[이심전심 15초]`)
  - **팀 인원 차이 보정:** 참여 인원이 가장 적은 팀의 인원(K명)만큼 각 팀에서 무작위로 K명을 뽑아 평균을 냅니다. 이 방식으로 팀 인원이 달라도 1등 확률이 같아지는 것을 시뮬레이션으로 확인했습니다. 보정을 끄려면 `config.js`에 `window.SCORING = { fairSample: false };`를 넣습니다.
- **포상:** 순위·빙고·팀순위 아래에 `1등: 신세계상품권 10만원`, `3~5등: 쿠팡이츠 3만원`처럼 적습니다. 추첨은 `경품: 스타벅스 1만원`을 씁니다.
  - 상품명으로 카드 그림이 자동으로 정해집니다. 커피·배달·상품권·지원금·선물 다섯 종류가 있습니다.
  - 실제 상품 사진을 쓰려면 사진을 저장소에 올리고 `1등: 상품명 | prize/사진.png`처럼 적습니다.

### 🆕 목차 · 게임 묶음 · 몸풀기 · 비공개 추첨
```
[목차] 오늘의 순서                 ← 모든 [세션]을 카드로 나열

[다른글자찾기 30초] 🧩 몸풀기       ← 폰에 글자판, 다른 글자 하나 찾기 (틀리면 1.5초 멈춤)
곰 = 공                            ← 기본 글자 = 숨은 글자
1~50등: 스타벅스 아메리카노 | prize/starbucks-americano.png   ← 마지막 "깜짝 선물 공개" 때만 보임

[게임] ⚡ 스피드 퀴즈               ← 다음 [게임결과]까지가 한 게임 (점수 따로 집계)
1등: 신세계상품권 10만원 | prize/shinsegae-100000.png
[퀴즈 10초] ...                     ← 문제마다 정답 공개 때 오른쪽에 이 게임 TOP 10 (마지막 문제는 정답만)
[게임결과] ⚡ 스피드 퀴즈 결과       ← 먼저 "여기까지!" → 진행자가 🏆 결과 발표 누르면 1~10등 + 상품
여기까지!

[순위] 👑 Game 왕                   ← 세션 안의 모든 게임 점수 합산 (상품 줄을 안 쓰면 상품 없음)
[추첨 3명 비공개] 🎁 행운상 추첨     ← '비공개': 세션 소개 화면에 안 나옴
```

### 🖼️ 상품 이미지 넣기
저장소에 `prize` 폴더를 만들고 아래 이름으로 이미지(정사각형 PNG/JPG 권장)를 올리면 실제 사진이 나옵니다. 파일이 없으면 기본 일러스트가 나와요.
`prize/baemin-30000.png` · `prize/starbucks-americano.png` · `prize/shinsegae-100000.png` · `prize/shinsegae-50000.png`
(파일명을 바꾸고 싶으면 콘텐츠의 `| prize/...` 부분만 같이 바꾸면 됩니다.)

### 💌 감사 인사
```
[감사 3명] 올해 가장 고마웠던 동료는?
1등: 감사상 30만원 지원
2등: 감사상 20만원 지원
3등: 감사상 10만원 지원
```
- 진행 순서: **입력 열기 → 입력 마감 → 🏆 결과 발표 → 🤝 One Team 피날레**
- 진행 중에는 대형 화면에 받은 사람 이름이 워드클라우드로 나오고, 많이 받을수록 커집니다. 아래에서는 최근 멘트가 4초마다 바뀌며 흐릅니다.
- 결과 발표를 누르면 1·2·3등 카드에 멘트 최대 4개와 상품이 나옵니다. 이 결과는 발표 순간의 집계로 고정됩니다.
- One Team 피날레에서는 이름과 멘트 카드가 가운데 나타났다가 작아지며 "One Team" 글자를 이룹니다. 약 20초 걸리고, 버튼을 다시 누르면 다시 재생됩니다.
- 이름은 참가자 명단에서 자동완성됩니다. 띄어쓰기, "님", 직급, (팀) 표기는 자동으로 떼고 같은 사람으로 셉니다.
- 같은 동료를 여러 번 적어도 1표로만 셉니다. 본인 이름은 적을 수 없고, 한 사람당 기본 3명까지 보낼 수 있습니다(`[감사 5명]`처럼 바꿀 수 있음).
- 동점이면 그 득표에 먼저 도달한 사람이 위입니다. 보낸 사람은 어디에도 공개되지 않고, 받은 사람은 결과 발표 후 폰에서 자기에게 온 메시지를 모두 볼 수 있습니다.

### 점수 구조
- **개인 점수 = 퀴즈 점수만** 집계합니다. 문제당 정답 100점에 빠르기 보너스가 최대 50점까지 붙습니다. `[순위 퀴즈]`가 이 점수로 개인 시상을 합니다.
- **팀전 점수 = 팀 게임 순위 점수**입니다. 게임마다 1등 100점, 2등 70점, 3등 50점, 4등 30점을 받고, `[팀순위]`가 이 누적 점수로 팀 시상을 합니다.
- 순위 화면은 진행자가 그 순서를 여는 순간의 점수로 **고정**됩니다. 이후에 게임을 더 했다면 **다시 집계** 버튼을 누르세요.
- **빙고:** 포상 인원(1~3등 등)만큼 완성자가 나오면 대형 화면이 자동으로 시상 화면으로 바뀝니다.
- **포상 지급 명단:** 진행자 화면의 **참가자** 탭에 모든 당첨 내역이 모이고, **명단 복사** 버튼으로 엑셀에 붙여넣을 수 있습니다.

## 6. 당일 진행 흐름
1. **행사 전:** 참가자 URL을 미리 배포합니다. 상태가 "대기"인 동안 접속한 사람은 "곧 시작합니다" 화면만 봅니다.
2. **행사 시작:** **▶ 행사 오픈**을 누르면 참가자가 이름과 팀을 입력하고 입장합니다. 대형 화면에는 접속 QR 코드와 주소가 표시됩니다.
3. **순서별 진행:** 왼쪽 목록에서 순서를 고르거나 **다음 ▶**을 누른 뒤, 오른쪽 버튼으로 진행합니다.
   - 투표·워드클라우드: 열기 → 마감
   - 퀴즈: 문제 시작 → 시간이 끝나면 자동 마감 → 정답 공개·채점
     - 점수는 정답 100점에, 빨리 맞힐수록 최대 50점이 더해집니다 (문제당 100~150점).
   - 팀 게임: 시작 → 제한시간이 끝나면 자동 마감 → **결과 발표**를 누르면 팀전 점수가 지급됩니다.
   - 빙고: 빙고 시작 → 🎲 단어 뽑기
     - 참가자의 빙고판은 자동으로 만들어지고, 뽑힌 단어가 자동으로 칠해집니다.
     - 완성 순서는 서버 시간 기준이며, 진행자 화면에서 판을 다시 계산해 검증합니다.
   - 추첨: 인원 수와 대상(현재 접속자만 / 이전 당첨자 제외)을 정한 뒤 🎰 추첨
   - 순위: 개인 TOP 10과 팀 순위(팀원 평균 점수)를 보여 줍니다.
4. **마무리:** 🏁 **종료**를 누르면 참가자 폰에 감사 화면과 최종 점수가 표시됩니다.

## 소리 (효과음 · 배경음악)
- 모든 소리는 `sound.js`가 브라우저에서 직접 합성합니다. 음원 파일이 없어 저작권 문제가 없습니다.
- 소리는 **대형 화면 PC에서만** 나옵니다. 참가자 폰은 무음입니다.
- 대형 화면을 띄운 뒤 화면을 **한 번 클릭**해야 소리가 켜집니다. 브라우저 정책 때문이며, 왼쪽 아래에 노란 버튼이 보입니다.
- 진행자 화면 위쪽에서 배경음악 켜기/끄기, 볼륨, 효과음 켜기/끄기를 조절할 수 있습니다.
- 퀴즈 카운트다운, 추첨, 탭 레이스 중에는 배경음악이 자동으로 작아집니다.

## 점수 규칙 바꾸기
`config.js` 맨 아래에 다음을 추가하면 기본값 대신 이 값을 씁니다.
```js
window.SCORING = { correct: 100, speedBonus: 50, team: [100, 70, 50, 30] };
```

## 참고
- 휴대폰을 바꾸거나 창을 닫았다가 같은 이름과 팀으로 다시 입장하면 점수가 이어집니다.
- 리허설이 끝나면 참가자 탭 → **전체 초기화**를 누릅니다. 콘텐츠는 그대로 유지됩니다.
- 행사가 끝나면 데이터베이스 규칙의 `yearend` 항목을 `false`로 바꿔 잠가 두세요.
- 사내 와이파이에서 접속이 안 되는 사람은 모바일 데이터(LTE/5G)로 접속하도록 안내하세요.
